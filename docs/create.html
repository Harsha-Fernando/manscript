Create

manscript create does two different jobs. Outside a project it starts a new folder. Inside a project (a directory that has manscript.toml, or a child of one) it adds an app or module. It will not nest another startproject inside an existing one.

New project

From an empty folder that is not already a ManScript project:

manscript create
  1. Language: Python, Ruby, C, C++, or Java.
  2. Framework, if that language has any. Python offers Django, FastAPI, Flask, and None (language only). Ruby offers Rails, Sinatra, and None. C, C++, and Java skip this step.
  3. A folder name (letters, numbers, hyphens, underscores).

ManScript then writes the folder, an isolated environment under .manscript/environment, starter files, and manscript.toml. Next:

cd the-name-you-chose
manscript run

-y answers yes to confirmation prompts. It does not run the full wizard by itself. Without a language and name, interactive create still needs a terminal.

Optional shortcuts (scripts / CI), not the usual path:

manscript create django myproject
manscript create python myapp
manscript create c hello

What we support

Language Frameworks Language only
Python Django, FastAPI, Flask picker None, or id python
Ruby Rails, Sinatra picker None, or id ruby
C — c
C++ — cpp
Java — java

macOS, Linux, and Windows via rustup and Cargo. On Windows, C and C++ need a real compiler (LLVM or MinGW). Git’s cc.exe stub is not enough. Java needs JDK 17 or newer.

What a new project gets

  • Django — django startproject in the project env, pinned Django, default run is python manage.py runserver.
  • FastAPI — app plus uvicorn; default run is uvicorn on port 8000.
  • Flask — app; default run is Flask on port 5000.
  • Rails — rails new via the project gems; default run is bin/rails server.
  • Sinatra — app.rb and Gemfile; default run is ruby app.rb.
  • Python only — main.py and empty requirements.txt; run is python main.py.
  • Ruby only — app.rb and a bare Gemfile; run is ruby app.rb.
  • C — main.c; run compiles with the project cc shim then executes app.
  • C++ — main.cpp; same with c++.
  • Java — Main.java; run runs javac then java -cp . Main.

Inside a project

Stay in the project folder (anywhere that still finds manscript.toml).

manscript create
This project is What create adds
Django Asks App vs Model, then a name. manscript create blog is an app (startapp, INSTALLED_APPS, urls, hello view at /blog/hello/). manscript create model Post appends a model, registers it in admin, then makemigrations and migrate.
Rails Asks kind: scaffold, resource, controller, or model, then a name. One argument is the name; it still asks which kind. Example: manscript create scaffold Post.
Flask A blueprint.
FastAPI A router.
Sinatra Another routes file, required from app.rb.
python, ruby, c, cpp, java Nothing to generate. Language-only trees are just files.

Other commands

  • manscript doctor — machine checks; does not change files.
  • manscript setup — runtime, environment, dependencies.
  • manscript install — dependencies into the project env.
  • manscript run / test / build — from [commands] in manscript.toml. Language-only run is not treated as a web server. C/C++/Java compile before run when needed.
  • manscript env — paths for this project.
  • manscript init — write manscript.toml in an existing directory.
