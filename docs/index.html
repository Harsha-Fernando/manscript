ManScript 0.1.3

From project folder to running app

ManScript prepares an isolated environment from manscript.toml, then runs the right project tools without activation rituals or permanent PATH changes.

Install ManScriptBrowse commands

Quick start in three steps

1

Create

manscript create

Choose Python, Ruby, C, C++, or Java and an available framework.

2

Enter the folder

cd myproject

Use the project name you entered in the wizard.

3

Run

manscript run

ManScript uses the project's managed environment and configured command.

Choose your onboarding path

New project

manscript create
cd myproject
manscript run

Learn what create generates.

Existing, not configured

cd existing-project
manscript init
manscript setup
manscript run

Review the new configuration before setup.

Cloned ManScript project

cd cloned-project
manscript setup
manscript run

Use this path when manscript.toml already exists.

What do you need to do?

Install or updateGet Rust, Cargo, ManScript, and completion scripts. Create or extend a projectUnderstand stacks, generators, and naming rules. Edit configurationSee every field and the argv security model. Fix a problemDiagnose PATH, project, environment, runtime, and toolchain issues. Use project tools directlyOpen a temporary project-aware child shell. Remove ManScriptRemove the CLI and, optionally, cached tools and completion setup.

What stays unchanged

Your system Python, Ruby, Java, compilers, parent terminal, and shell startup files remain yours. Project environments live under .manscript/environment; downloaded runtime tools use ~/.manscript or MANSCRIPT_HOME.
