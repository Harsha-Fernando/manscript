ManScript

A language-agnostic CLI. It prepares an isolated environment from manscript.toml so you can go from zero to manscript run without activating a venv or fighting PATH.

It does not replace Python, Django, Ruby, or Java. Those tools stay on your machine. ManScript runs the copies inside this project’s environment.

What you get

  • create — new project, or an app/module inside one
  • Python: Django, FastAPI, Flask, or language-only
  • Ruby: Rails, Sinatra, or language-only
  • C, C++, Java — language-only hello + compile/run

Systems

macOS, Linux, and Windows. Install is the same idea everywhere: Rust (Cargo), then ManScript. Homebrew and Chocolatey are not the 0.1 path.

On Windows, C and C++ need a real compiler (LLVM or MinGW). Git’s cc.exe stub is not enough.
