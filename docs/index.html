ManScript

A language-agnostic CLI. It prepares an isolated environment from manscript.toml so you can go from zero to manscript run without activating a venv or fighting PATH.

It does not replace Python, Django, Ruby, or Java. Those tools stay on your machine. ManScript runs the copies inside this project’s environment.

After install, start a project with manscript create. ManScript asks which language, which framework (or none), and a name. What we support and what happens inside an existing project is on Create.

Updates are not automatic. Pull the repo and run cargo install --path . --force — see Install.
