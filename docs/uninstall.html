Uninstall

ManScript is a Cargo binary plus optional cache folders. Removing it does not remove your system Python, Rust, Java, or compilers.

1. The CLI

cargo uninstall manscript

That deletes manscript from Cargo’s bin directory.

2. Downloaded tools (optional)

If ManScript fetched runtimes into your home directory:

macOS and Linux

rm -rf ~/.manscript

Windows (PowerShell)

Remove-Item -Recurse -Force "$env:USERPROFILE\.manscript"

If you set MANSCRIPT_HOME, delete that folder instead.

3. Project environments (optional)

Each ManScript project has an isolated env at .manscript inside the project. Delete that folder, or delete the whole project if you do not need it.

macOS and Linux

rm -rf /path/to/your-project/.manscript

Windows (PowerShell)

Remove-Item -Recurse -Force .\path\to\your-project\.manscript

Rust itself

Leave Rust if you still use it. To remove rustup as well: rustup self uninstall — that is separate from ManScript.
