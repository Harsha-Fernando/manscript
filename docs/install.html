Install

0.1.1 ships as source. You install Rust, then compile ManScript with Cargo. You do not need Homebrew or Chocolatey.

1. Rust

Use rustup. That is the usual way to get rustc and cargo.

macOS and Linux

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

On macOS, if compile fails, install Xcode Command Line Tools: xcode-select --install.

On Debian/Ubuntu, you may need: sudo apt install build-essential.

Windows

Download and run the installer from rustup.rs (64-bit). The MSVC toolchain is the default and is fine. After it finishes, open a new terminal so cargo is on PATH.

Check:

cargo --version

2. ManScript

Clone the repo (you need access if it is private), then install from the project folder:

git clone https://github.com/Harsha-Fernando/manscript.git
cd manscript
cargo install --path .

That puts manscript in ~/.cargo/bin (Windows: %USERPROFILE%\.cargo\bin). If the shell says command not found, add that directory to PATH and open a new terminal.

manscript doctor
manscript create

With no extra arguments, ManScript asks: language, then framework (or None), then a folder name. C, C++, and Java skip the framework question. When it finishes:

cd myproject
manscript run

Use the name you typed at the prompt, not necessarily myproject.

Scripts and CI can skip the prompts with extra arguments, for example manscript create django myproject. That is optional. The usual way is still manscript create. Full detail: Create.

Tab completion

Once manscript is on PATH, the shell can complete the binary name. To also complete commands after it, load the script for your shell (zsh is shown; also bash, fish, powershell, elvish):

eval "$(manscript completions zsh)"

Put that line in ~/.zshrc (or the equivalent for your shell) so it survives new terminals. Then Tab after manscript lists commands, and Tab after manscript create suggests stacks such as django or python.

Update

ManScript does not update itself. There is no background updater. When a new version is published, you install it again the same way you installed it the first time.

cd manscript
git pull
cargo install --path . --force

--force is required: Cargo will not replace a binary that is already named manscript, even if the source changed. manscript --version should read 0.1.1 after this release. After a source-only change at the same version number, that is still the command.

If you later install from crates.io, it would be cargo install manscript --force (and a version pin if you want one). That is not the 0.1 path yet.

What this does not install

Rustup does not install Django. A Django project still needs a Python that ManScript can detect (or download via its provider). Java projects need a JDK 17+. C/C++ need cc / c++ that can actually compile, not a stub.
