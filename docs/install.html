Getting started

Install ManScript

Version 0.1.3 is distributed as source. Install Rust, then let Cargo compile the manscript binary. Homebrew, Chocolatey, and downloadable binaries are not part of this release.

1. Install Rust and Cargo

Use the official installer at rustup.rs.

macOS and Linux

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
cargo --version

macOS may also need Xcode Command Line Tools: xcode-select --install. Debian or Ubuntu may need sudo apt install build-essential to compile Rust dependencies.

Windows

Run the 64-bit rustup installer and accept the default MSVC toolchain. Open a new PowerShell or terminal after installation, then run:

cargo --version

2. Install ManScript

git clone https://github.com/Harsha-Fernando/manscript.git
cd manscript
cargo install --path .
manscript --version
manscript doctor

Cargo normally writes the executable to ~/.cargo/bin, or %USERPROFILE%\.cargo\bin on Windows.

If the command is not found

Open a new terminal first. If that does not help, add Cargo's bin directory to your user PATH. See PATH troubleshooting.

3. Pick your next command

New project

manscript create
cd myproject
manscript run

Existing project

cd existing-project
manscript init
manscript setup
manscript run

Cloned configured project

cd cloned-project
manscript setup
manscript run

Shell completion

manscript completions prints a script; it does not edit your shell configuration. Choose one supported shell:

# zsh
eval "$(manscript completions zsh)"

# bash
eval "$(manscript completions bash)"

# fish
manscript completions fish | source

PowerShell and Elvish are also supported. To make completion persistent, put the appropriate command in that shell's startup configuration. Tab completion covers subcommands and known create stack identifiers.

Update

ManScript has no automatic updater. Open a terminal in the ManScript source folder you cloned during installation, then run:

git pull
cargo install --path . --force
manscript --version

Do not type a placeholder such as /path/to/manscript. The command must run from the real folder containing ManScript's Cargo.toml.

Language prerequisites

Python and Ruby can use a suitable system runtime or an isolated runtime prepared by ManScript. C and C++ require a working system compiler; Java requires a JDK 17 or newer with both javac and java. ManScript creates project shims for those toolchains but does not download a compiler or JDK.
