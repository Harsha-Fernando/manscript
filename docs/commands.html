Commands

Commands that need a project search the current directory and its parents for manscript.toml. An “environment” means the prepared tools under that project's .manscript/environment.

manscript create [stack-or-name] [name]

Outside a project, starts the interactive wizard or creates a named stack directly, such as manscript create django myproject. Inside a project, generates a framework item. It may write source and configuration files, create an environment, install packages, or run framework generators. See Create.

manscript init

Writes manscript.toml in the current directory for an existing project. Interactive mode asks for language and optional framework. With --yes, current behavior chooses Python and the first registered Python framework. If the file already exists, it reports that and leaves it unchanged.

cd existing-project
manscript init
# review manscript.toml
manscript setup

manscript setup

Resolves the configured runtime, creates the project environment when needed, and installs dependencies. Runtime downloads require confirmation unless --yes is supplied.

manscript install

Reinstalls project dependencies using the prepared environment. It does not create a missing environment; a missing environment is an error with a manscript setup recovery hint.

manscript run [args...]

Runs [commands].run and appends trailing arguments as literal argv values. A configured run command and prepared environment are required. C, C++, and Java builds are prepared before execution when needed.

manscript run --port 9000

manscript test [args...]

Runs [commands].test with appended arguments. If no test command is configured, ManScript reports that there is nothing to do and exits successfully.

manscript build [args...]

Builds language artifacts through the adapter or runs [commands].build. C compiles main.c, C++ compiles main.cpp, Java compiles Main.java, and Rails runs bin/rails assets:precompile. A project with neither adapter build behavior nor a build command reports that there is nothing to do.

manscript doctor

Read-only diagnostics for the platform, ManScript version, Python and venv, pip/uv, Ruby and Bundler, C/C++ compilers, and Java JDK. Inside a project it also checks whether the project environment is ready.

manscript env

Shows the project root, configured language/framework, environment and tool-bin paths, optional runtime provider, preferred commands, and environment readiness. It does not create the environment.

manscript shell

Opens an interactive child shell in the project root with managed tools first on its PATH. Requires a configured project and prepared environment. See the shell guide.

manscript completions <shell>

Prints a completion script for bash, zsh, fish, powershell, or elvish. Redirect or evaluate it using your shell's conventions. ManScript does not install it automatically.

Global options

  • -y, --yes: accept supported confirmation prompts for CI or non-interactive use.
  • -h, --help: show help.
  • -V, --version: show the installed version.
